# 文档规范

本仓库文档面向运行与维护求职Agent的读者，不依赖作者本机配置或聊天记录。

|目录|用途|命名|
|---|---|---|
|`guides/`|安装、配置、使用和维护|小写英文词，以连字符连接|
|`design/`|生产代码机制与取舍|小写英文词，以连字符连接|

开头说明用途；操作按使用顺序，机制按执行顺序。首次术语给必要解释，文件名用于定位。区分已经验证、设计支持及尚未验证，不把引用存在当作语义正确。

目录根部保留`README.md`、本规范和`AGENTS.md`。不要把实验、私人运行输出或真实JD放入文档。修改路径时修复引用；新增文档在目录登记。命令从项目根目录执行，使用可替换路径，不写作者个人绝对路径。
